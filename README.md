## 第二题预览

六个静音代码预览直接复用最终 Demo 的粒子工厂与绘制器。用户提供的 SVG 半身剪影参与头肩碰撞：雨滴溅开、烟花反弹、礼物粒子散成彩带。人物使用纯灰色填充、黑色背景，按参考图居中贴底并略向下留出开花空间；5:3 横向画幅，SVG 共享缓存，烟花保持协调比例；不加载照片或识别模型。预览与体验共用左右交替的发射规划及间隔：写实约1.5–1.66秒、礼物约1.75–1.95秒、扁平约1.4–1.5秒。物理时间与粒子工厂保持一致，预览静音且采用固定表情强度。连续播放不会在单次烟花结束时重置，扁平三种花型合并轮换，花朵尺寸按画幅固定，头部左右移动时仅调整位置与花心间距；写实与礼物粒子首次接触轮廓即响应。素材来源见 ASSET_SOURCES.md。默认自动播放；点击画面暂停／继续，画面底部内嵌进度条支持定位。减少动态效果偏好下默认暂停。移出视口或隐藏页面后暂停绘制，不加载识别模型或音效。礼物图集解码共享。

`effect-preview/` 只用于展示动画；真实表情、头部、身体和手部碰撞在独立体验链接中使用摄像头运行。

本仓库不包含 Sites 访问凭证、私人备份、历史模型与旧版预览。
